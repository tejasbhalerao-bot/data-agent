# Project Brief — Nano Fulfilment Centres

## Objective
Expand Truemeds' hyperlocal serviceability by identifying where to open Nano Fulfilment Centres (NFCs).

## Fulfilment Construct at Truemeds
| Type | Status | Notes |
|------|--------|-------|
| Fulfilment Centres (FCs) | Live | Full-size, full-inventory |
| MicroFulfilment Centres (MFCs) | Live | Smaller size, shallower inventory |
| Nano Fulfilment Centres (NFCs) | Proposed | Smaller than MFCs, even shallower inventory depth |
| Distribution Centres (DCs) | Live | Existing |

NFCs are smaller and carry shallower inventory than MFCs.

## Definitions
- **Hyperlocal** = Same Day Delivery (SDD) or Next Day Delivery (NDD)

## Core Question
Which locations (pincodes / geographies) should we open NFCs in to expand hyperlocal serviceability?

This is a **site selection problem**: find pincodes with meaningful order demand that are not currently served by SDD or NDD, where placing an NFC would unlock hyperlocal coverage.
